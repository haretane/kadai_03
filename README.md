## ⑤工夫した点・こだわった点
・スマホネイティブで作ってます<br>
・同じお店で買いたい商品は、連続で入力して追加できる<br>
・買ったらタップでグレーアウト&取り消し線。（買ったことがわかる）<br>
→不要になったら削除できる<br>
・過去に入力した単語はリストででる。（初期設定である程度使いそうなお店は登録済み）<br>
・「登録」を押さなくてもエンターキーで登録できる

## ⑥難しかった点・次回トライしたいこと（又は機能）
ひとつの value に商品を追加で複数いれられるようにしたのですが、
構造が難しかったです。
